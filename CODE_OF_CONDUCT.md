# Code of Conduct

## Our Commitment

we are committed to fostering a welcoming, respectful, and inclusive community for everyone, regardless of experience level,
background, identity, or perspective.

Our goal is to make PR Coach a place where people can learn, collaberate, and improve together.

## Expected Behavior

Membors of our community are expected to:
- Be respectful and professional.
- Assume good intentions.
- Give constructive, actionable feedback.
- Be open to receiving feedback.
- Ask questions without fear of judgement.
- Help create an environment where everyone feels comfortable contributing.
- Focus discussions on improving the project.

## Unacceptable Behavior

The following behaviors are not acceptable:
- Harassment, discrimination, or personal attacks.
- Trolling or intentionally disruptive behavior.
- Insults, intimidation, or abusive language.
- Publishing another person's private information without permission.
- Deliberatly creating a hostile or unwelcoming environment.
- Bad-faith partisipation intended to derail discussions.

## Code Review Expectations

Code reviews should focus on the code - not the person.

When reviewing code:
- Explain **why** a change is suggested.
- Be specific and respectful.
- Encourage discussion when there are multiple valid approaches.
- Recognize that every contributor is still learning something.

When receiving feedback:
- Assume reviewers want to improve the project.
- Ask for clarification if something is unclear.
- Remember that suggestions are about the code, not your ability.

## Scope

This Code of Conduct applies to:
- Github issues
- Pull requests
- Discussions
- Project documentation
- Community spaces associated with PR Coach

## Reporting Concerns

If you experience or witness behavior that violates this Code of Conduct,
please open a private communication with the project maintainer.

Reports will be reviewed fairly and respectfully. Every reasonable effort will
be made to protect the privacy of those involved.

## Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

Depending on the severity of a violation, maintainers may:
- Request that inappropriate behavior stop.
- Remove comments or content.
- Close issues or pull requests.
- Temporarily restrict participation.
- Permanently ban contributors who repeatedly or seriously violate this Code of Conduct.

## Our Philosophy

PR Coach exists to help developers grow.

We believe that curiosity, kindness, and continuous learning lead to better software - and to better engineering communities.

Thank you for helping build a community where everyone can learn and contribute with confidence.
